# Fabricatable-Axis-6
A low cost linear actuator for digital fabrication machines. Open hardware designed in open software. Easy to 3D print parts with an easy to source BOM.

*Status: Under development, assembled but not properly tested*

### BOM

**For two bearing rings - Large** *Two sets of bearing rings needed for one axis*
- 608 2RS bearing (with rubber seal on both sides)- 12pcs
- M8 screw - 40mm length (any scew head type works) - 12pcs - *to function as axles for the bearings*
- M5 set screw - preferably 10mm length (any normal M5 screw 16mm length or more will also work, but will protrude) - 6pcs - *for fine tuning bearing pressure*


**Additional hardware for the belt drive version**
- M5 hex socket head 1-16mm length - 4pcs - *to attach the nema23 stepper*
- GT2 timing gear pulley - 8mm bore - for 9mm wide belts - 20 teeth - 1pcs - *to drive the belt*
- GT2 timing belt 9-10mm wide - with fiber arming - 1pcs - *to position the carriage on the axis*


**Additional hardware for the bicycly drive version**
- Standard 1/2 inch link length bicycle chain - 1pcs *adjust paremteres in the FreeCAD file to compensate for chain waear*
- 608 2RS bearing (with rubber seal on both sides) - 4pcs
- M8 screw - 40mm length (any scew head type works) - 2pcs
- M8 screw - 80mm length - 1pcs
- Short M3 screws - unknown amount
- A few M8 washers - Unknown amount
- M5 set screw - preferably 10mm length - *for locking the pinion on the motor shaft*
- Short M5 screws - 8pcs - *for attaching the motor to the motor platean dthe motor plate to the carriage*

**For one bearing ring - Samll** *Two sets of bearing rings needed for one axis*
- 625 2RS bearing (with rubber seal on both sides)- 12pcs
- M5 screw - 20mm length (any scew head type works) - 12pcs - *to function as axles for the bearings*
- M3 set screw - preferably 10mm length (any normal M5 screw 16mm length or more will also work, but will protrude) - 6pcs - *for fine tuning bearing pressure*
